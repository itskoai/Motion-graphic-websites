## Shared APIs (read the source, it is short)
- `lib/scene.ts`
  - `useSceneProgress(ref, { start, end, pin, pinSpacing, scrub, material, stop, onProgress, disabled })` writes `--p` (0..1) on the ref element across its scroll range and calls `onProgress(p, direction)` (throttled to 0.001 steps, scrub-smoothed). `pin: true` pins the ref element (`end: '+=300%'` means 300vh of scroll). `material: 'ink'` inverts the page while active. `stop: [sheet, n]` updates the SC readout. `disabled: true` for reduced motion (sets `--p: 1`).
  - `seg(p, a, b)` maps p inside [a,b] to 0..1; `smooth(t)` smoothstep. `setOverMedia(true)` makes the header transparent over full-bleed footage (call it from the hero when zoom > 0.6; call `setOverMedia(false)` when it ends).
- `lib/motion.ts`: `useMotionMode()` → `{ reduced, saveData, compact (≤767px), touch, landscapePhone, ready }`. `ready` is false on the server and first paint: render the complete static layout then.
- `lib/frames.ts`: `useFrameSequence(urls, enabled)` → `{ loaded, done, nearest(i), get(i) }` coarse-to-fine loader; `heroFrames(count, base, pad, ext, start)` builds URL lists; `drawCover(ctx, img, w, h)`.
- `components/window/LetterWindow.tsx` (THE signature primitive; read its header comment):
  `<LetterWindow ref={h} as="h1" className="hl-xl" text="שעוד לא ראית[ם]." media={{kind:'video', sources:[{src:'/media/door-loop.webm',type:'video/webm'},{src:'/media/door-loop.mp4',type:'video/mp4'}], poster:'/media/door-poster.jpg', loop:true, focus:[0.14,0.5]}} mediaB={{kind:'frames', urls, poster}} active={near} grade={0.85} restScale={1.5} />`
  `[x]` marks the window letter (must be one of ם ה ת ח ד ר מ ן כ ב ך). Add the class `win-off` (or `ghost`) on the LetterWindow element to close the window and show the letter as plain text (used during an entrance tween, for retired words, and for reduced motion without media). `h.current.set({ zoom, frame, mix, grade, opened })` from `onProgress` (no React renders). `zoom` 0 = inside the letter, 1 = roof fills the viewport (full-bleed). `frame` 0..1 scrubs a frames media. `mix` crossfades media→mediaB. `opened:false` = solid ink letter. `restScale` = how much of the media is visible through the letter at rest (1.2 close, 2.2 wide). Media only decodes while `active`. It renders real text (SSR) plus a canvas; the zoom canvas is portaled to body at z-index 30 (below the header at 50). Media sources: webm first, then mp4 (the test browser plays only webm).
- `components/ui/Viewer.tsx`: `const { open } = useViewer(); open({ title, sources, poster, aspect: 'portrait'|'wide'|'cinema', note }, buttonEl)` opens the site-wide video dialog.
- `components/ui/Rule.tsx`: `<Rule />` the ballpoint rule that draws itself on enter (or `progress={p}` controlled). Put it inside an element with `color: var(--accent)`; e.g. the CTA: `<a className="cta" href="#contact">{label}<Rule className="rule" /></a>` (`.cta .rule` is styled in globals).
- `content/he.ts` → `he.<scene>.*`. `site.config.ts` → `siteConfig` (contact, founders, socials, forms.endpoint, projects urls). Empty strings mean "hide or show the designed placeholder".

## Forms (Final and Coming only)
POST JSON (`Content-Type: application/json`, `fetch` same-origin) to `siteConfig.forms.endpoint` (default `/api/lead.php`, a PHP file in `public/api`; in the dev server it does not run, so the fetch returns a non-JSON 200 or 404: treat anything but `{ok:true}` as failure and show the honest failure state). Fields: inquiry → `{ kind:'inquiry', name, contact, message, page: location.pathname, website:'', elapsed }`; notify → `{ kind:'notify', email, consent:true, consentText: he.coming.consent (exact string), source:'coming'|'final', page, website:'', elapsed }`. `website` is a honeypot (hidden input, must stay empty); `elapsed` is the ms between the first focus inside the form and submit and must be ≥ 1500 or the server rejects it (so block submit before 1.5s with a gentle wait, never fake it). Errors map: `required|contact|email|consent|rejected|rate|full|...` → `he.final.err*` / `he.final.fail`.
